# 逆水寒手游副本首席记分工具

这是一个用于逆水寒手游副本首席竞选记分的网页小工具，支持按成员录入各副本排名，自动换算积分并进行多人总分对比。

## 主要功能

- 支持多人录入与排名对比
- 支持“单周 + 上周积分”“两周周成绩”“周成绩换积分”三种计算模式
- 支持五项副本项目积分换算：
  - 燃心画境·六人
  - 六人本
  - 团本·外
  - 团本·内
  - 燃心画境·团本
- 提供积分速查，可输入排名快速查看五项积分与合计
- 数据会保存在浏览器本地，刷新页面后仍可继续使用

## 使用方式

1. 选择需要的计算模式。
2. 添加或修改成员名称。
3. 按成员录入各副本排名，工具会自动计算每项积分与总分。
4. 在“对比结果”中查看成员排序、总分和项目明细。
5. 需要快速查排名对应积分时，可使用底部“积分速查”。

## 本地运行

```bash
npm install
npm run dev
```

启动后按终端提示打开本地地址即可使用。

## 构建

```bash
npm run build
```
